1. Introducción a HTML

HTML es el lenguaje de marcado estándar para crear páginas web. A continuación, veremos diferentes niveles de encabezados con sus párrafos correspondientes.

2. Qué es una etiqueta?

Una etiqueta HTML es un fragmento de código que define cómo se debe mostrar el contenido.
